# Oficina de Jogos

Este repositório contém o código usado na oficina de desenvolvimento de jogos Web realizada na Semana Nacional de Ciência e Tecnologia (SNCT) 2026. Foi escolhido um jogo simples, um labirinto _top down_, para mostrar conceitos básicos de desenvolvimento de jogos, tais como mapa, personagem e controle, colisão, pontuação, entre outros.

## Premissa

O ano é 2084. A IA chegou à singularidade, e decidiu que o ser humano é totalmente descartável. Para sobreviver, um grupo de rebeldes decide invadir o sistema, a Matrix, e resgatar o conhecimento acumulado de várias cientistas brasileiras. Por isso, você precisa assumir o controle de um avatar e chegar até o centro do labirinto, onde fica a IA mãe.
